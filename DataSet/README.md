## DataSet

This folder contains the input data required to run the analyses in this repository.

### Files

**um-het3-rqtl.csvr**
The main genotype and phenotype file for the UM-HET3 population, formatted for R/qtl v1.
Load it with `read.cross()` using `genotypes=NULL` and `na.strings=c("-", "NA")`.
Contains genotype probabilities at 891 markers and phenotypes (lifespan, covariates) for 6,438 mice.

**bodyweights/**
Body weight measurements at multiple ages (42, 90, 120 days, 6, 12, 18, 24 months) for UM-HET3 mice,
sourced from GeneNetwork (ITP_10003.csv, ITP_50601.csv) and an additional dataset (bw_RichM.txt).

**regions/**
Confidence intervals and top markers for all Vita loci from the 4-way mapping analysis.
- `regions_4way_merged.txt` — proximal and distal boundaries per locus
- `regions_4way_topm.txt` — top marker position per locus
- `regions_4way_merged_effects.txt` — genotype effect sizes (days) per locus per genotype

**genage/**
Reference gene lists from the [GenAge database](https://genomics.senescence.info/genes/) used
for candidate gene prioritization.
- `genage_human.csv` — human aging-associated genes
- `genage_models.csv` — model organism aging-associated genes (*C. elegans*, *Drosophila*, etc.)

**output/**
Intermediate output files generated by the analysis scripts. Empty on a fresh clone.

### External data

Full lifespan and body weight data for 24,296 ITP mice is available on GeneNetwork:
[genenetwork.org](https://genenetwork.org/show_trait?trait_id=10001&dataset=HET3-ITPPublish)
